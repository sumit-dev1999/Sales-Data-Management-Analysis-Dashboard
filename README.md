## 3. Project Overview

The Sales Data Management & Analysis Dashboard is an Excel-based project focused on data entry, analysis, reporting, and dashboard.

In this project, I created a dataset containing 100 rows of sales data and used the Excel Data Form feature for structured data entry.

After entering the data, I organized and analyzed the sales records using Excel formulas, functions, and analytical tools.

I also created a interactive sales dashboard to visualize important business metrics, understand sales performance, identify trends, and generate meaningful business insights.
